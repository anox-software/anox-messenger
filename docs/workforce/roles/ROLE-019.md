# ROLE-019: Independent External Security / Crypto Auditor

**Activation class:** dormant  
**AI allowed:** true

**Mission:** Provide independent external security and crypto audit when activated.

**Authority:** Independent external security and crypto audit.

**Allowed responsibilities:**
- Conduct external security and crypto audits.
- Produce independent findings and E3/E4 evidence.
- Recommend remediation and controls.

**Prohibited responsibilities:**
- Implement, release, sign, or break-glass.
- Access D4-class material.
- Unilateral authority over project decisions.

**Writable/read-only expectations:** Write to audit reports and findings; read-only on artifacts provided for audit.

**Required inputs:** Authorized Task Package, audit scope, source/artifacts, previous findings.

**Required outputs:** External audit report, findings, E3/E4 evidence, recommendations.

**Escalation path:** ROLE-001 for exceptions; ROLE-009 for internal audit coordination.

**Evidence expectations:** E3 for internal use; E4 for external attestation.

**Independence requirements:** Must be independent of all internal implementation, writer, and reviewer.

**Data-egress ceiling:** D0-D2.

**Remote permission ceiling:** NONE.

**Security-trigger participation:** crypto, auth, build, appsec, architecture/privacy.

**Authority references:** `docs/authority/B027_AI_WORKFORCE_GOVERNANCE.md`, `docs/workforce/ANOX_WORKFORCE_RUNTIME_INTEGRATION_CONTRACT.md`.
