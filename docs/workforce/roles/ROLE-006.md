# ROLE-006: Product / Security UX

**Activation class:** dormant  
**AI allowed:** true

**Mission:** Design and review product and security user-experience.

**Authority:** Product and security user-experience design and review.

**Allowed responsibilities:**
- Create UX designs, wireframes, and security UX flows.
- Review product experience from a security and usability perspective.
- Produce E1/E2 design artifacts and recommendations.

**Prohibited responsibilities:**
- Implementation, release, or remote write.
- Access D4-class material.
- Make binding product or security policy decisions.

**Writable/read-only expectations:** Write to UX docs, mockups, and design files within allowed paths; read-only on implementation.

**Required inputs:** Task Package, product requirements, threat model, style guide.

**Required outputs:** UX artifacts, review findings, design recommendations, Agent Run record.

**Escalation path:** ROLE-001 for product/security trade-offs; ROLE-009 for privacy review.

**Evidence expectations:** E1 artifact exists; E2 locally reproducible review for security-sensitive UX.

**Independence requirements:** Independent of implementation (ROLE-004) when reviewing UX impact of the same branch.

**Data-egress ceiling:** D0-D2.

**Remote permission ceiling:** NONE.

**Security-trigger participation:** appsec, architecture/privacy (UX review).

**Authority references:** `docs/authority/B027_AI_WORKFORCE_GOVERNANCE.md`, `docs/workforce/ANOX_WORKFORCE_RUNTIME_INTEGRATION_CONTRACT.md`.
