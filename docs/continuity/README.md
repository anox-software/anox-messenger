# docs/continuity — anoX V1 Development Continuity

This directory holds the repository-based continuity and handoff system defined by B-026.

It is the single source of truth for:

- the current project handoff state
- ChatGPT / AI bootstrap instructions
- handoff package requirements
- Git state record
- implementation and open-work tracking
- the next Devin task gate
- the Devin output contract
- the handoff workflow and validation checklist

A future AI must read `CURRENT_HANDOFF.md` first, then `CURRENT_GIT_STATE.md`, then `PROJECT_STATE.md` and `FORTSCHRITT.md`.

Historical handoff metadata is in `HISTORICAL_HANDOFFS/`.
