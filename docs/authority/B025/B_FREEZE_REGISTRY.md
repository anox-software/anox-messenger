## Export recoverability note

The original verbatim assistant messages for some middle Track-B turns were not all available as standalone files when this artifact was generated. This package therefore preserves the **current accepted architecture rules and B-024 amendments** rather than pretending to reproduce missing verbatim text. When an exact parameter is not explicitly present in this package, an implementation agent must not invent it. Search the original chat/source first; if it cannot be recovered, create a new explicit ADR/freeze before implementing that parameter.
